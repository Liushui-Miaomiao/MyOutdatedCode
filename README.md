# MyOutdatedCode（我的过时代码）

## 简介

这是一个收集了我近十年从开始学习编程中，产生的部分还能找到的一些僵尸代码或资料，这些仅仅也只是部分，许多中间产物或因误删或因不明原因再也没能找到。

因此为了避免再次出现这种情况，同时也为了能够给自己一路走来的技术历程做小总结，我建立了这个仓库，并选择将它公开，这些代码对于我已经没有任何用处，但是可能或许会对一些有需要的人，去了解这些【遗产】（其实一开始想的是每个僵尸项目做一个仓库，但想了想一个是这些都是没用的僵尸代码，不可能再有什么更新价值，另一方面会把我的个人主页污染，因此聚在一个仓库我觉得最好这样）。

此仓库的所有代码或资料百分百纯个人手写，使用 MIT 协议发放，希望这些【遗产】可能会对有兴趣的人尽可能多的给予一些帮助，亦或从中窥探过去那个跌跌撞撞的自己。

由于此仓库上的所有代码基本都是我曾经的僵尸项目，因此我觉得我可能不会再去编译或者再去验证这些项目里的代码是否存在 BUG，每个项目我也会简要的写一份 README 来大致介绍这个项目是做什么的。但是我非常欢迎，如果你觉得你想帮我修复一些什么问题，或者补充 README 没说全的地方，来为这个项目提交 PR 请求。
