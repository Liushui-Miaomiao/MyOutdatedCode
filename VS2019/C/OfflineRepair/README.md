# OfflineRepair

这是大学那会，为了解决 BVN 的一个老毛病（PC 本地端），就是加载完成播放制作组动画结束后要进入主菜单时，突然闪退的情况，后来查明其实是 win_ui 组件一个 RSL 库导致的，这个库需要远程从 Adobe 服务器下载已签名且还在有效期的组件，因为离线状态下如果没有缓存这个组件，就会加载失败，这个工具就是在相关位置补上这个文件的，因此可以做到修复效果。至于为什么要归为废弃代码，一个是因为当时技术不够好，写的不是很合规，二是更重要的，Adobe 这个组件是有时效性的，今年（2026 年）就出这档子幺蛾子，工具不好使了，是因为旧版组件签名到期了，我这个工具又没更新新版组件，而且有个悖论，没网的情况下我又怎么去获取新版组件，总不能每次发布新版组件，我就手动更新一次程序吧，这个问题得想办法解决，就先废弃了。
