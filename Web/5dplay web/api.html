什么是 API ？
API （Application Programming Interface，应用程序接口）

是一些预先定义的接口（如函数、HTTP接口），或指软件系统不同组成部分衔接的约定。 用来提供应用程序与开发人员基于某软件或硬件得以访问的一组例程，而又无需访问源码， 或理解内部工作机制的细节。
简而言之，就是一组由操作系统或服务提供者面向开发者提供的系统函数， 具体实现由操作系统或服务提供者实现，而开发者或用户无需了解底层架构， 从而加快编程实现的的一种东西。
API 使用起来难吗？
不难。

如果你曾经有过任何一种程序开发经验的话，应该都会或多或少的接触到系统相关的函数， 而这些函数其实就是该语言默认的API。
e.g.
在C语言中，打印一条语句到终端我们会使用 printf() 函数， Java中，则是 System.out.printfln() 函数， 这些函数其实就是该语言面向我们（开发者）提供的 API 函数， 我们并不清楚该函数的内部运行原理，但我们知道应该如何传入参数和接收相应的返回值， 这个函数只给出了相应的输入和输出，内部实现就像一个暗箱一样， 这就叫做函数的 封装。所以函数封装的本意就是让复杂的函数简单化， 不用让开发者重复造轮子。
