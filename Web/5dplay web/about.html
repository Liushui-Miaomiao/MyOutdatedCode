关于我们
5DPLAY Game Studio，我的娱乐工作室。

成立于 2007年，创始者 剑jian， 一直致力于创作优秀、好玩的游戏作品。
旗下优秀作品有： 《死神vs火影》、《妖尾vs海贼王》 和 《海贼王巅峰对决》等。
其中 《死神vs火影》 和 《妖尾vs海贼王》 为当下热门小游戏，经久不衰。
《死神vs火影》 从 2009年 开始发行公测版本 0.6，到如今 2021年发布 3.5版本， 已经走过了 13 年，期间不断完善游戏机制， 提升玩家游戏体验，紧跟时代脚步， 全面推出 Windows 端和 Android 端游戏，相信我们会更加努力为玩家制作更多优秀作品。
