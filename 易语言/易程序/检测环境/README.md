# 检测环境

早期配合 OfflineRepair 项目一起研究的，用来检测 BVN 为什么首次在断网的机器上运行时会闪退的原因，写了三种检测，一个是有没有安装 .NET Framework 2.0 的库，这个一般除了 XP 不自带，其余版本 Win 都自带，然后检查了最主要的 RSL 缓存，这个缓存就是 Adobe 一个需要验证签名的一个运行库，后面 2025 年旧改版（以 3.3 为模板制作的大量改版）集体闪退也是这东西搞的鬼，这玩意不存在或者过期就会闪退，最后检查了下是否有声卡驱动，因为早期 BVN 的代码里没有对声音设备进行验证，好像是那个 SoundChannel，这玩意在没显卡的设备上会返回 null，所以在没声卡的设备上（虚拟机，学校机房之类）就会闪退。

一开始也是准备先写易语言版本，后面用 C 再去实现（因为易语言老生常谈的报毒问题），但这玩意也是越放越没用，遂废弃了。后来接触到黑月编译，把这玩意弄成黑月编译了。
